# Phase 5: セル分割＋数字OCR

## 目的

補正後の正方形画像を9×9に分割し、各セルから数字を認識する。空欄判定も含める。

## 完了条件 (Definition of Done)

- [ ] OCRエンジンの最終選定（ML Kit Text Recognition or 軽量CNN or 他）
- [ ] Development Build セットアップ手順を `docs/` に追記
- [ ] `src/ocr/segment.ts`: 補正画像を 9×9 にスライス
- [ ] `src/ocr/recognize.ts`: 各セル → `Cell` 型（0〜9、0は空欄）
- [ ] サンプル画像（少なくとも1〜2枚）で精度確認
- [ ] OCR誤認識率の傾向をメモ
- [ ] Gitコミット（日本語メッセージ）

## 設計判断

実装時に追記。以下を確定する:

- 認識前のセル前処理（二値化・モルフォロジー処理）の有無
- 信頼度しきい値・空欄判定アルゴリズム
