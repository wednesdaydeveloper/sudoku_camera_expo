# Phase 4: 盤面検出（手動4点指定）

## 目的

撮影画像から数独盤面の領域を抽出し、正方形に補正する。MVP では自動検出を採用せず、ユーザーが4隅をタップして指定する方式で実装する（ADR-004）。

## 完了条件 (Definition of Done)

- [ ] `src/grid/CornerPicker.tsx`: 画像上で4つのハンドルをドラッグ可能なUI
- [ ] 初期位置は画像の四隅（適度に内側）
- [ ] `src/grid/perspective.ts`: 4点 → 正方形（推奨 900x900px）への変換ロジック
- [ ] `expo-image-manipulator` または同等手段で補正画像を生成
- [ ] 補正後の見た目を確認できるプレビュー画面
- [ ] Gitコミット（日本語メッセージ）
