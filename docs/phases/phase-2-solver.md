# Phase 2: 数独ソルバ（純ロジック）

## 目的

画像処理を抜きにして、9×9の盤面データから解を計算する純粋なTypeScriptモジュールを作る。これにより画像処理が完成する前に「手入力 → 解答」が動く状態を作り、後続Phaseのリスクを下げる。

## 完了条件 (Definition of Done)

- [ ] `src/solver/types.ts` に `Cell` / `Board` / `SolveResult` 型を定義
- [ ] `src/solver/validate.ts` で初期盤面の妥当性チェック（行/列/3×3ボックスに重複なし）
- [ ] `src/solver/solve.ts` でバックトラック解法を実装
- [ ] 既知の数独問題で Jest テストが通る（easy / medium / hard 各1問以上）
- [ ] 解けない問題（矛盾あり）には `{ status: 'invalid' | 'unsolvable' }` を返す
- [ ] `npm test` グリーン
- [ ] Gitコミット（日本語メッセージ）
- [ ] phase-2-solver.md の「実装内容／動作確認／引き継ぎ」を埋める
